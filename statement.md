# Project Statement

## Problem Statement
Students and academic mentors may need an early estimate of expected academic performance. This project predicts a student's final score from study hours, attendance, previous score, assignment completion, sleep hours, and extracurricular hours.

## Scope
The system covers CSV data loading, validation, preprocessing, supervised regression, evaluation, model persistence, and prediction through a Java Swing interface.

## Target Users
- Students
- Faculty and mentors
- Academic analysts
- Java/ML learners

## High-Level Features
1. Data loading and validation
2. Data preprocessing
3. Linear Regression training
4. Model evaluation
5. Prediction
6. Desktop GUI
